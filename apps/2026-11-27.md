# New Apps — 2026-11-27

## Fossible HIS (Biograph) — open-source hospital information system on Frappe/ERPNext

- **What:** A production-grade Hospital Information System built natively on Frappe and ERPNext — EHR, outpatient/inpatient care (OPD/IPD, ADT, bed management), lab (LIS with LOINC), radiology (RIS with DICOM), pharmacy, billing and insurance/RCM, inventory, HR/payroll and accounting on one database and one API. It is a fork and enhancement of Marley Healthcare, built by Tacten / FossibleWorks and launched publicly on 24 November 2026. Standards: FHIR R4, HL7, DICOM, LOINC, ICD-10, SNOMED-CT; HIPAA-ready, with ABDM and NABH support. Agent-ready out of the box — every doctype exposes REST, and Hydra MCP gives AI agents a typed, permissioned tool surface over the whole system. GPL-3.0, $0 per-user fees, self-host anywhere. Also available as a one-click install on Frappe Cloud.
- **Why it helps:** Hospitals and clinics are a strong ERPNext vertical — they need OPD/IPD, pharmacy, lab, billing and HR in one system, and this is exactly that, already built. NexTash can offer hospital implementations without building the clinical side from scratch, and the ERPNext Healthcare base means existing Healthcare-module knowledge transfers directly.
- **Note:** the GitHub repo was renamed from `biograph` to `HealthCentral` and its default branch is `biograph-fh`; the Frappe app inside is named `healthcare`. The product site calls it "Fossible HIS", the repo README calls it "Biograph" — same system.
- **GitHub:** https://github.com/Tacten/HealthCentral
- **Install:** `bench get-app https://github.com/Tacten/HealthCentral`
- **Source:** https://www.fossibleworks.com/products/fossible-his/ · launch listing: https://www.nicheloom.com/launches/115993/

## rx_pharmily — connector from a pharmacy's ERPNext to RxPharmily (niche)

- **What:** A small Frappe app that links a pharmacy's ERPNext to RxPharmily (a Supabase-based pharmacy platform). The chosen selling price list is pushed with the pharmacy's own item codes a few seconds after a price changes, plus a full sync every night; untick "Share with RxPharmily" on an Item to keep it out. Only an encrypted refresh token is stored, never the password. Created 26 November 2026.
- **Why it helps:** Only if a pharmacy client already uses RxPharmily — a narrow connector, not a general-purpose app. 0 stars, no license listed, so treat it as early and unproven. Not added to [new-apps.md](../new-apps.md).
- **GitHub:** https://github.com/AlexanderApps/rx_pharmily_frappe
- **Install:** `bench get-app https://github.com/AlexanderApps/rx_pharmily_frappe`
- **Source:** https://github.com/AlexanderApps/rx_pharmily_frappe

### uae_wps — UAE Wage Protection System salary files for Frappe HRMS

- **What:** A Frappe app that generates UAE WPS (Wage Protection System) salary files from HRMS payroll — the fixed-format files UAE employers must submit through their bank so salaries are paid compliantly. It adds WPS Salary File, WPS Agent and WPS File Format doctypes, payroll hooks and custom fields, plus unit tests. Created today, 27 November 2026. MIT licensed.

- **Why it helps:** Any client with staff in the UAE has to file WPS salary files every pay cycle — doing it by hand from payroll exports is slow and error-prone. This gives NexTash a ready-made WPS add-on to offer Gulf clients instead of building the file format from scratch.

- **Note:** brand new (0 stars, created hours ago) and the README does not yet document the file format or setup steps, so treat it as early and unproven — pilot it on a staging bench against a real WPS file before promising it to a client. Not added to [new-apps.md](../new-apps.md) yet for the same reason.

- **GitHub:** https://github.com/souravs72/uae_wps

- **Install:** `bench get-app https://github.com/souravs72/uae_wps` (default branch `stable`), then `bench install-app uae_wps`

- **Source:** https://github.com/souravs72/uae_wps
