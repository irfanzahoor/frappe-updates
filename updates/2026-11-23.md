# Daily Update — 2026-11-23

## ERPNext v16.60 released — 17 November 2026

Frappe released Framework, ERPNext, and Frappe HR v16.60, one month after v16.50. Over 2,500 bugs were fixed in the preceding month.

Sources:
- https://frappe.io/blog/product-updates/announcing-framework-erpnext-and-frappe-hr-v1660
- https://discuss.frappe.io/t/announcing-v16-60-for-frappe-framework-erpnext-and-frappe-hr/165819

### What is new

1. **Frappe Studio is now part of Framework**
   - Build complete apps and custom UIs without writing code.
   - High-fidelity customisation on top of ERPNext.

2. **Frappe Flow (alpha)**
   - Frappe's own AI harness that runs alongside Frappe apps, inside Desk.
   - Permission-aware AI. Still a pre-release — more updates expected in December.

3. **Dashboards, powered by Insights**
   - Insights dashboards are now viewable directly inside Desk, with drill-downs linked to real records.
   - Standard dashboards in ERPNext and Frappe HR now ship as Insights dashboards.
   - Multi-axis charts, maps, heatmaps, trend lines, and more.

4. **Projects module revamp (phase 1)**
   - New project overview: progress, blocked and overdue tasks, costing, and billing.
   - More improvements planned for the December release.

5. **Customer and Supplier forms revamped**
   - New Overview dashboard inside Customer and Supplier forms.
   - Restrictions can now be added directly from those forms.

6. **Report printing redesigned**
   - New standard print formats for Statement of Account, Customer/Supplier Bill-wise Pending, Balance Confirmations, Sales/Purchase Registers, and Warehouse Stock Summaries.
   - New Day Book report, and a cumulative option in the Cash Flow report.

7. **New importer for child tables**
   - Follows the data-import popup pattern from v16.50, supports more file types and column mapping.

8. **Mobile UX improvements**
   - Better navigation, filters, and new components like bottom sheet.

### What it means for you

- **If you build custom apps:** try Studio first for UI-heavy customisation before writing custom code — it may save a lot of development time.
- **If you run ERPNext v16:** v16.60 is a strong upgrade candidate, but test custom apps, print formats, and integrations in staging first, especially before enabling Insights or Studio workflows.
- **If you are still on v15:** v15 is still maintained (v15.125.0 shipped 12 November 2026), with support planned until end of 2027 — upgrading is a planned decision, not a forced one.
- **If you do manufacturing / finance:** check the new Day Book, Cash Flow cumulative option, and the Production Plan reservation fix in v16.60.

### Also noted

- ERPNext v15.125.0 — 12 November 2026: date-range validation in reports, company default accounts / cost centers / warehouses validation, and 21 fixes.
