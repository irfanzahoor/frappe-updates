### What is new

1. **ERPNext v15.126.0 — 22 November 2026 (v15 maintenance)**
   - Cash Flow report gains the "Accumulated Values" option (cumulative amounts by period), also in v16.60.
   - POS Invoice returns now exclude change already given, so the refund matches the original sale total.
   - Fixes across Production Plan, Work Order and Stock Entry (material reservations, transfer/finished quantities, BOM Creator display).
   - Permission hardening: Warehouse, Bin, Batch and Item Tax Template lookups now respect read permissions; customer portal users can no longer see drop-ship Purchase Orders; POS stock is limited to warehouses of companies the user can access.
   - Sales Invoice / POS Invoice change calculation and split-refund rounding fixed.

2. **Frappe CRM v16.3.0 — 20 November 2026**
   - Open Flow (AI harness) from the CRM sidebar.
   - Frappe Cloud v2 site owners are asked to set a password.
   - Same day, v16.2.0 added a live CRM preview in guided setup; v16.1.0 (19 Nov) improved telephony calls, WhatsApp agent notifications and guided setup.

3. **Frappe Helpdesk v16.2.1 — 20 November 2026**
   - The v16.2 line brings a Studio-built customer portal, knowledge-base subcategories and pinned articles, ticket list grouping with counts and totals, and an agent status that clears automatically after a set time.
   - Also: shared Email Accounts settings panel, skills for frappectl & MCP, and onboarding setup for Frappe Cloud v2 sites.

4. **Frappe Insights v3.50.3 — 20 November 2026**
   - Patch on the big v3.50 rebuild: every chart redrawn on frappe-ui charts, Insights dashboards inside Desk, and ready-made dashboards for ERPNext and Frappe HR.
   - Breaking change in v3.50: v2 code is removed — sites still on Insights v2 must migrate their v2 work first. Node v20.19 or later is required, and on Frappe v16, update Insights together with the v16.60 releases.

5. **Frappe Framework v16.60.1 / v16.60.2 — 17–18 November 2026**
   - v16.60.1 restricts email creation (`email.make`) to system users — website users can no longer use it.
   - v16.60.2 fixes reordering/editing unsaved rows in form tables.

### Weekly changes, 16–22 November 2026

- **Frappe:** 33 new features, 7 speed-ups, 67 fixes, 16 refactors. Flow agents can now be public (guests can chat), Flow asks an admin before using the site’s Grove key, and MCP/Flow agents see desk field rules so they stop saving documents the desk would reject. Desk v2 gets a DocType sidebar of views, a save bar and a view switcher. Printed PDFs can now be attached to the document.
- **ERPNext:** 2 speed-ups, 145 fixes, 7 refactors — including a fix for stock deadlocks when many Stock Entries are submitted at once, and the permission hardening listed above.
- **Frappe HR:** 3 new features, 6 fixes — Employee Profile page, Job Offer / Appointment Letter / Org Chart v16 bundle, and Insights workbooks for employee lifecycle and recruitment. Daily Work Summary is removed.
- No breaking changes this week.

### Security — November advisories

- Frappe’s November security advisories (published 6 November; CVE records published 21 November) cover 21 issues. The most serious is a Selling/Buying SQL injection (CVSS 7.7) that could let a portal user extract session data — fixed in 15.121.6 / 16.37.0. The broader authorisation fixes are complete in 15.124.2 / 16.53.0.
- If your clients run v15 or v16, check they are at or above those versions — current releases (v15.126.0 / v16.60.x) already include the fixes.
- Source (third-party summary of Frappe’s advisories): https://brandefense.io/security-news/erpnext-november-security-advisories-session-exposure/

### What it means for you

- **If you run v15 sites:** v15.126.0 is a safe maintenance update — apply it on staging first, then production. The permission-hardening fixes can change portal behaviour (drop-ship POs hidden from customers, POS stock limited by company access), so check any custom portal code or scripts that relied on the old behaviour.
- **If you run CRM / Helpdesk:** small upgrades, low risk. Helpdesk v16.2’s Studio-built customer portal is worth a look if a client uses the portal — it is a rebuild, so test it before switching clients over.
- **If you use Insights:** v3.50 is a major upgrade, not a routine patch. Migrate any v2 dashboards first, check Node is 20.19+, and upgrade Insights together with the v16.60 apps.
- **If you manage client sites:** confirm every site is on at least 15.124.2 / 16.53.0 for the November security fixes.
