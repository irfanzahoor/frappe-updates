### What is new

1. **ERPNext v16.61.0 — 25 November 2026**
   - A large maintenance release: **278 bug fixes, 3 new features, 1 performance improvement** across General (15), Accounts (11), Selling (23), Buying (14), Stock (70), Manufacturing (83), Subcontracting (51), Assets (4), Projects (3), CRM (3) and Setup (1).
   - **Stock — 2 new features:** an opt-in weekly check in **Stock Reposting Settings** (*Auto Repost Incorrect Valuation Entries*) that reviews Stock Ledger Entries from the current fiscal year and submits a Repost Item Valuation for the first incorrect entry per item and warehouse; and a **valuation breakdown page** for an item and warehouse, opened from the Incoming/Outgoing Rate columns in the Stock Ledger report, showing how each entry changes value and per-unit rate (batch, serial and backdated entries included).
   - **Manufacturing — 1 new feature:** a **"Return Components"** option on draft **Job Cards**, returning unused materials to their source warehouse while the Work Order is open, so they can be issued again.
   - **Performance:** **Skip Unchanged Entries** in Repost Item Valuation — recalculations stop after a Stock Reconciliation that resets the balance or when the balance stops changing, so unaffected later entries are not reprocessed.
   - **The big theme is permission hardening:** POS Invoice item searches now reject POS Profiles the user cannot view; company defaults and accounting defaults are only returned for Companies the user can read; adding items checks access to the selected Customer/Supplier and Price List; Payment Entry only shows records the user can view; Print Format options in Payment Request are limited to permitted formats; Sales Order calendar and Gantt views now apply the same access rules as the list view.
   - **POS and invoicing fixes:** Sales/POS Invoice now decides cash change by comparing the paid amount with the rounded total; split refunds that match stay in separate payment rows; automatic write-offs are calculated from the rounded outstanding amount.
   - **Manufacturing and subcontracting** get the deepest fixes: Job Card elapsed-time counting, Production Plan reservations and quantities, BOM costing and process loss, subcontracting receipts/returns and cost allocation, and stock reservations released correctly on cancellation.
2. **ERPNext v15.127.0 — 25 November 2026**
   - The v15 backport of the same fixes — including the POS Profile access checks, company-defaults scoping, "Update Items" row validation, pricing-rule and conversion-rate fixes on item UOM changes, and the internal-customer same-rate checks.
3. **Frappe CRM v16.4.0 — 25 November 2026**
   - One feature: a standard **Insights dashboard is now drawn on the CRM dashboard page** (backport of #2963) — CRM users get the standard analytics view without opening Insights separately.
4. **Frappe Helpdesk v16.2.2 — 25 November 2026**
   - Three small fixes: Flow chat keyboard focus, allowing the Flow server callback past `block_endpoints`, and showing the full name beside the user avatar. v15.2.1 carries the same fixes for v15.

### What it means for you

- **If you run v16 sites:** a routine patch, low risk — update on staging first as usual. The permission-hardening fixes are the ones to watch: if a client user suddenly cannot see a POS Profile, a company default, or a print format, this release is why — check their roles and permissions rather than treating it as a bug. The Stock valuation breakdown page is genuinely useful for debugging wrong valuation rates on client sites.
- **If you run manufacturing clients:** this is a good release to prioritise — 83 manufacturing and 51 subcontracting fixes, plus the Job Card "Return Components" option and the faster Repost Item Valuation. Test on staging with a real production plan and subcontracting flow before rolling out.
- **If you use CRM:** the Insights dashboard on the CRM dashboard page is a small quality-of-life win — worth showing to sales-team clients.
- **If you run v15 sites:** v15.127.0 brings the same fixes, so v15 clients are not left behind.
- **No Framework, HRMS, Insights or Raven release today:** Framework's latest is still v16.61.0 (24 Nov), HRMS v16.60.0 (17 Nov), Insights v3.50.3 (20 Nov), Raven v3.2.0 (28 Oct).

### New apps worth checking today

See the full list in [new-apps.md](../new-apps.md). New today:

- **frappex-client** — a typed Python client (sync + async) for the Frappe / ERPNext REST API, announced 25 November. The official `frappe-client` is archived and was never on PyPI, so most integrations hand-write `requests` calls — this replaces that with typed methods, automatic pagination (`iter_list`), a typed exception per failure, and safe retries (writes are never retried, so a network error cannot create duplicate documents). HTTPS-only with certificate checks that cannot be disabled, secrets never logged. Tested against Frappe v14, v15 and v16, MIT licensed. `pip install frappex-client` — GitHub: https://github.com/Padmapriyan27/frappex-client — docs: https://frappex-client.zeal.ninja
